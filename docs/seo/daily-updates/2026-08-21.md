## Part 2 — Pick one “boss page” for each topic

**Ticket / sheet names:** OWNERSHIP sheet, CHG-012, CHG-008

### Why

Imagine many kids all yelling the same answer in class.  
The teacher gets confused.

Search works the same way.  
If many pages try to rank for “Miami yacht rental,” Google gets mixed up.

So we pick **one boss page** for each topic.  
Other pages can help.  
They should point to the boss page.

### Boss pages to approve first

| Topic | Boss page | How many pages fight it |
|-------|-----------|-------------------------|
| Miami boats | `/miami-yacht-rental/` | 134 |
| Miami parties | `/miami-yacht-party/` | 15 |
| Miami superyachts | `/miami-super-yacht-rentals/` | 65 |
| Food / catering | `/miami-catering/` | 127 |
| Panama boats | `/panama-yacht-rentals/` | 57 |
| Fort Lauderdale | `/fort-lauderdale-yacht-rentals/` | 35 |

### Also fix copycat / twin links

Some links look like their own page but really open another page.

Examples:
- `/miami-yacht-rentals/` (with an **s**)
- `/yacht-specials/`
- `/miami-yacht-deals/`

For each one, choose:
- make it a **real different** page with its own job, **or**
- treat it as a twin and always link to the boss page instead

Also: some boat links are broken or missing. Fix or remove them (CHG-008).

### Do not do this

- Do not merge Miami city hubs with 301 redirects
- Do not make `/miami-yacht-rentals/` and `/miami-yacht-rental/` both “#1 boss”
