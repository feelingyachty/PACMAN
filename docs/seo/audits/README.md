## How to approve

Open the Excel → `START_HERE` → `CHANGE_QUEUE`. Set **Approve_?** to Approve, Reject, or Hold. Corey/Pacman only implement approved tickets. `ALL_PAGES` is the full inventory; `ISSUES` is one row per problem; `BROKEN_OR_ALIASES` is internal links that are aliases or missing from the sitemap.
