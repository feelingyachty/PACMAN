# Feeling Yachty — Elementor notes

Elementor is the page builder layer on Feeling Yachty WordPress sites.

## Agent guidance

- Prefer Flexbox containers over legacy sections when building new layouts (see official Flexbox help mirror).
- Theme / widget / hook customization: use `developers.elementor.com` mirrors under `official/`.
- Do not invent a new visual system; match existing Feeling Yachty branding on the live site.
- Structural page data often lives in Elementor JSON stored in post meta — change carefully and verify on staging when possible.

## Official mirrors

See `docs/elementor/official/` — refreshed every Monday.
